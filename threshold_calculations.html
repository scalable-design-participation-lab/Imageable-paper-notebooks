In this notebook I obtain the thresholds used in the framework for Boston and Monterrey. Each threshold is a percentile of one feature, computed over the validation buildings of each city:

  1. P10 sharpness
  2. P10 sky visibility
  3. P10 facade visibility
  4. P10 ground visibility
  5. P10 number of detected facade lines
  6. P10 mean line detection confidence
  7. P90 vegetation
  8. P75 building height
  9. P90 image entropy
  10. P75 distance to neighbours

The vegetation, the distance to neighbours and the street view height come from data.json. These are normalized, so we transform them back to their original units with the scaler. The image quality descriptors and the real heights come from preparation_experiment_3.json, which we computed in the third experiment.

Functions to get the percentiles

The number of detected lines and the mean line confidence are not stored as fields, they are computed from the lines and scores lists of every building.

def get_percentile(percentile, feature_name):
    index = feature_names.index(feature_name)
    feature_array_monterrey = [monterrey_data_inverted[i][index] for i in range(0, len(monterrey_data_inverted))]
    feature_array_boston = [boston_data_inverted[i][index] for i in range(0, len(boston_data_inverted))]

    percentile_value_monterrey = np.percentile(feature_array_monterrey, percentile)
    percentile_value_boston = np.percentile(feature_array_boston, percentile)

    return percentile_value_monterrey, percentile_value_boston

def get_percentile_from_image_qual_data(
        data_boston,
        data_monterrey,
        percentile,
        feature_name,
    ):
    subdata_boston = [x[feature_name] for x in data_boston]
    subdata_monterrey = [x[feature_name] for x in data_monterrey]

    percentile_monterrey = np.percentile(subdata_monterrey, percentile)
    percentile_boston = np.percentile(subdata_boston, percentile)

    return percentile_monterrey, percentile_boston

def get_percentile_from_derived(
        data_boston,
        data_monterrey,
        percentile,
        derive,
    ):
    subdata_boston = [derive(x) for x in data_boston]
    subdata_monterrey = [derive(x) for x in data_monterrey]

    percentile_monterrey = np.percentile(subdata_monterrey, percentile)
    percentile_boston = np.percentile(subdata_boston, percentile)

    return percentile_monterrey, percentile_boston
